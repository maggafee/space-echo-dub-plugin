DUBASCO TAPE ECHO - Installation macOS
======================================

1. Plugins kopieren
   - "Dubasco Tape Echo.component"  ->  ~/Library/Audio/Plug-Ins/Components/      (Audio Unit, für Logic)
   - "Dubasco Tape Echo.vst3"       ->  ~/Library/Audio/Plug-Ins/VST3/            (VST3, für Ableton)
   (~ ist dein Benutzerordner. Im Finder: Gehe zu > Gehe zum Ordner... und den Pfad einfügen.)

2. WICHTIG: Gatekeeper-Sperre lösen
   Das Plugin ist nicht von Apple notarisiert. macOS blockiert es deshalb nach dem Download
   (Meldungen wie "kann nicht geöffnet werden", "ist beschädigt" oder Logic meldet das AU als
   fehlerhaft). Das behebst du einmalig im Terminal (Programme > Dienstprogramme > Terminal).
   Diese Zeilen einfügen und jeweils Enter drücken:

     xattr -rd com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/"Dubasco Tape Echo.component"
     xattr -rd com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Dubasco Tape Echo.vst3"

   Für die Standalone-App (falls du sie nutzt), z. B. im Programme-Ordner:
     xattr -rd com.apple.quarantine /Applications/"Dubasco Tape Echo.app"

   Danach Logic bzw. Ableton neu starten.

3. Logic Pro
   Hatte Logic das Plugin vorher schon als fehlerhaft markiert: Logic Pro > Einstellungen >
   Plug-in-Manager, "Dubasco Tape Echo" auswählen und "Zurücksetzen & Auswahl erneut prüfen" klicken.
   Zu finden unter Audio-FX > Audio Units > Dubasco > Dubasco Tape Echo.

4. Ableton Live
   Einstellungen > Plug-Ins > "VST3 Plug-In System Folders" an, ggf. "Neu scannen".

5. MIDI Learn
   Das Plugin hört direkt auf alle angeschlossenen MIDI-Controller, ein MIDI-Routing im Host ist
   nicht nötig. Oben "MIDI LEARN" klicken, einen Regler im Plugin anklicken, am Controller drehen.
   Die grüne Lampe am "MIDI"-Knopf leuchtet, sobald MIDI ankommt. Im MIDI-Menü siehst du die
   gefundenen Geräte und die zuletzt empfangene Nachricht.
